# Brasil Cars

Loja Angular de veículos em Blumenau, Santa Catarina — estoque próprio de seminovos, 0 km e utilitários.

## Como rodar

```bash
npm start
```

Acesse `http://localhost:4200/`.

## O que o site inclui

- Home da loja com busca e destaques do pátio
- Estoque com filtros e paginação
- Ficha do veículo com fotos reais, placa de vitrine Brasil Cars, WhatsApp e simulador
- Favoritos e comparação
- Páginas da loja: sobre, contato e FAQ

Stack: Angular 19, standalone components e signals.
